# plan.md — 設計

## 役割
- Claude Code: 設計（本書）と最終検証（check.md）
- Codex（公式 codex:codex-rescue サブエージェント経由、モデル・effort はランタイム既定）: 実際の文章作成

## 入力
- brief.md のみ（架空「こもれびカフェ」の事実情報）

## 手順
1. Codex `--fresh` で brief.md から Instagram 投稿文 3案を作成 → `posts-before.md`
   - 各案 60〜90字目安、店名・営業時間・特徴を含める
   - 価格・駅からの距離・限定企画・売上は追加しない
2. Claude が posts-before.md を brief.md と照合
3. Codex `--resume`（同一タスク文脈）に修正を1点だけ依頼 → `posts-after.md`
   - 案1の最後の一文のみを「お店でお待ちしています。」に変更
   - 他は変更せず、既存の事実を保持。posts-before.md は上書きしない
4. Claude が事実と変更点を自分で検証 → `check.md`

## 事実チェック項目
- 店名：こもれびカフェ（架空）
- 営業時間：10:00〜18:00
- 特徴：コーヒーを飲みながら読書できる
- 予約：不要（記載する場合は矛盾しないこと）
- 禁止追加：価格・駅からの距離・限定企画・売上

## 失敗時
- ランタイム手順が失敗した場合、実際のエラーを check.md に記録して停止。成功を捏造しない。
