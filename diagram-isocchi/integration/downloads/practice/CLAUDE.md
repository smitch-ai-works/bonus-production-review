# この練習フォルダの役割分担

この練習フォルダだけで、次の役割分担を使ってください。
・Claude Code：依頼を整理し、完成条件を決め、結果を元情報と照合する。
・Codex：公式プラグインの /codex:rescue で、作成と修正を担当する。
・作成前に入力・完成条件・保存先を短く示す。
・同じファイルを同時に編集しない。元ファイルは上書きせず、修正前後を残す。
・確認で直す点があれば、Claude CodeからCodexへ具体的に返す。最大2往復で止め、残件を知らせる。
・外部送信・公開・課金・設定変更・削除は、実行前に僕へ確認する。
・使えない機能や足りない情報があれば、成功扱いにしない。
