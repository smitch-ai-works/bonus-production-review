いそっち式 AI社員づくり

2つのAIを、別々に使っている人へ

片方で考えた内容を、もう片方へ毎回説明し直していませんか？ この資料では、Claude CodeからCodexへ仕事を渡し、保存した実物を確認する流れをつくります。

まずは、下書き3本を任せてみる

いきなり大きな仕事を渡す前に、SNS投稿の下書きボードで一周してみます。

Claude Codeで設計読む人・テーマ・120字以内を決める
↓
Codexがファイルを作る3本の本文・文字数・コピーボタン
↓
Claude Codeで最終確認実物を開く → 必要ならCodexへ修正を返す

練習用の完成見本。本文のコピーと状態の変更を、ここでも試せます。

完成見本を大きく開く

使うのは、PCのClaude Code

Claude Code使えるアカウントと、練習用の作業フォルダ
CodexChatGPTアカウント・Node.js 18.18以上

Claudeの通常チャットではなく、PCで動くClaude Codeを開きます。設定と練習は、その作業フォルダで進めてください。

すでにある仕事のフォルダを上書きせず、練習用のコピーで試すと確認しやすいです。

練習ファイル一式を保存

ZIPを展開して guide.html を開くと、ガイド・指示文・完成見本を手元で使えます。PCのブラウザで閲覧。AIの実行には通信と各サービスの利用環境が必要です。

次の3つを、Claude Codeの入力欄へ上から1つずつ送信します。

/plugin install codex@openai-codex
/reload-plugins

確認の目印：Codexのコマンドが候補に並ぶこと。

候補が出ない・インストールで止まるとき

/plugin のInstalledで有効状態とインストール先を確認します。再読み込みの案内が出たら /reload-plugins を実行。エラーが残る場合は、内容を消さずに公式の手順と照合してください。

公式プラグインはChatGPTのFreeを含むプラン、またはAPIキーで利用できます。ここではChatGPTでのサインインを使います。使えるモデル・上限はアカウントや設定により異なります。

/codex:status は進み具合、/codex:result は保存された実行結果。完了の報告と、ファイルの確認は分けて見ます。

5

実物を見て、仕上げる

↓
修正後の方向設計と確認はClaude Code、作業はCodex。まずは小さな1件から。

「何が違うか」を返すときも、最初に決めた完成条件と照合します。

詳しい確認表を保存

確認欄はこのページを開いている間だけ有効です。記録を残すときは、保存した確認表を使ってください。

使用量は、担当ごとに使われる

Claude Code側設計・指示・結果の読み取り・確認
Codex側委任された制作・検査・修正

重い作業をCodexへ分けても、Claude Codeの指示や確認は残ります。やり取りを増やせば、使用量も増えるので、最初は小さく通してみてください。

チェックを増やす前に

公式プラグインには /codex:review と、終了時の任意レビューゲートがあります。reviewは読み取り専用で、修正は行いません。レビューゲートは往復が長くなり、使用量を早く消費する場合があるため、最初の練習では有効にしません。

公式のレビューゲート説明

この分担で、次に任せるなら

SNS投稿の台本読む人と構成 → 原稿 → 内容確認
LPやサイト伝える順番 → ファイル → 表示確認
集計とレポート集計条件 → 計算 → 元データと照合
リサーチの下調べ調べる問い → 収集 → 原典の確認

まずは、自分の仕事から「完成条件を言える1件」を選んで渡してみてください。
