# SNS投稿前チェック

## 作るもの
ブラウザーで開く1ページのチェックリスト `sns-check.html`。

## 読者と用途
個人でSNSを発信する人が、投稿する前に原稿と画像を確認する。

## 必須条件
- チェック項目は6つ。次の意味を保つ。
  1. 読む人の場面が一つ分かる
  2. 元の資料にない数字や経験を足していない
  3. 文章と画像で内容がずれていない
  4. リンク先と案内する内容が合っている
  5. 誤字と改行を見直した
  6. 公開する内容を自分で確認した
- 項目を押すとチェックできる。
- 完了数を `0 / 6` のように表示する。
- リセットボタンで全チェックを外せる。
- 日本語。スマホ幅320pxとPCで使える。
- HTML/CSS/JavaScriptを1つのHTMLに入れる。外部通信なし。
- チェック状態はページを開いている間のみ保持し、再読込でリセットする。
- 主色はチャコール、アクセントはアンバー。可読性を優先。
- 完了は投稿の許可や成果の保証を意味しない。自動投稿機能は作らない。

## 確認すること
6項目、完了数、リセット、320pxでの表示、外部通信なし。
