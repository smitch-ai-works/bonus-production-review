現在の比較は `cold-start-isocchi/`。いそっちさんの元特典をBeforeに、同じ2本の台本から新しく作ったAfterを並べています。特典、使用台本、渡した本人写真、元動画、全文の撮影台本、スキルZIP、前回の出力を開けます。

制作素材は台本と本人写真。活動名・CTAと提供内容・動画未受領は事前設定です。本人写真は元の公開表紙から人物部分をピクセル変更せず切り出したものです。前回制作した画像、作例、実演素材、スクショ、プロンプト、HTML/CSS/JS/SVGは制作担当へ渡していません。汎用スキルと参考サイトの観察は使用しています。

独立した制作担当が新しく画像と作例を制作し、実演・自己確認を行いました。その初回納品を保持したうえで、表示検品ツールをスキルへ追加し、同じ試行内で追加の自己修正を行っています。最終ZIPだけを最初から単独再実行した検証や、無修正1発の出力とは扱いません。公開担当は特典本文・画像・指示文を編集していません。公開する読者用38ファイルは、追加検品後の凍結manifestと同じバイトです。
