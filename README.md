# 特典作成スキルのBefore → After

公開済みの塗り絵しおり特典（台本No155）をBeforeにし、現行の配布スキルで新しく制作したAfterを比較します。同じ5柄、PNG1点の配布形式、線画→英語原稿→Etsyの工程とLINE案内先を固定しています。

入力は元台本・本人写真・既存の5柄PNGとPC実画面・使用した指示文・LINE情報・指定参考LPです。制作中の自己確認と修正を含み、台本だけの無修正出力という主張はしていません。公開担当は納品後のAfter本文・画像へ編集を加えていません。

入口と比較本体は `compare-no155/`。Beforeは取得時点の公開ページと元バイトが一致する保存版です。元の公開LPは変更していません。`evidence.json`に出所と比較条件を記録しています。ページの「元の動画」は対応する完成動画の閲覧用縮小版で、After制作への追加入力ではありません。

「使った台本」「解説動画の撮影台本」は折りたたみで閲覧できます。本人の16:9解説動画は撮影待ちです。使用したスキルZIPは `downloads/bonus-production.zip`。再生成は公開リポジトリ外の `update_before_after_demo.py`、従来の `update_demo_videos.py` からも現在の比較入口へ振り分けます。

以前の2例は `draft-v3/`、それ以前は `draft-v2/`・`draft/no197/`・`draft/no193/`・`repro/`・`sample/` に保持しています。
