# 特典作成スキルのデモ：いそっちさん Before → After

利用者指定の連携特典と塗り絵しおり特典を、そのままBeforeとしてリンクします。Beforeには元から属人性があります。各Googleドキュメントの台本を起点にスキルで制作し、本人FBを反映したいそっちさんのAfterを2例掲載しています。

本人の参照画像と各特典の案内先・提供内容は、利用者の回答によりBeforeから事前設定として継承しました。制作担当へ渡した本文の材料は台本部分で、Beforeの本文・コマンド・図解は渡していません。制作中の自己確認と修正を含み、文字どおり台本だけの無修正出力という主張はしていません。

2026-11-08の本人FBにより、表紙・本文人物画像・CTAの計8枚を、各Beforeの原写真を人物参照元として直接指定して再制作しました。生成済みの顔を人物参照元へ連鎖させず、原写真と目視照合する基準を配布スキルへ追加しています。画素一致や本人採用済みの主張ではありません。

表紙から本文・図解・CTAまで、連携は黒・青緑・金、塗り絵は黒・深緑・赤・金の世界観へ統一。本文の可読性と作例の元データを保ち、保存教材にも同じ画像とCSSを反映しました。本文の内容・撮影台本・プロンプト・印刷PDFは保持しています。このAfterはFB反映版です。初回制作時のスキルは `downloads/bonus-production-initial-isocchi.zip` に保持しています。

入口と比較本体は `compare-isocchi/`。Beforeは元のNetlify公開ページ、元動画は指定Instagram投稿、使用台本は指定Googleドキュメントへリンクします。元の特典や動画は編集・差替えをしていません。`compare-isocchi/evidence.json`に出所と入力条件を記録しています。

各例の「解説動画の撮影台本」は折りたたみで閲覧できます。本人の16:9解説動画は撮影待ちで、現在は全文撮影台本と上部掲載準備までです。使用したスキルZIPは `downloads/bonus-production.zip`。再生成は公開リポジトリ外の `update_isocchi_demo.py`、従来の `update_demo_videos.py` からも現在の比較入口へ振り分けます。

最新の配布スキルでは、実物・操作画面が不足した際、制作側で同じ作例を実制作してスマホ幅で撮影するか、必要な素材名と画面の状態を利用者へ具体的に依頼します。スマホ幅Web・実機アプリ・PC画面を区別し、素材待ちを完成扱いにしません。この更新はスキルの取得・依頼手順の改訂であり、掲載済み2例へ実操作スクショを新しく追加したものではありません。
