# 特典作成スキルのデモ

更新した特典制作スキルの初稿と、No197・No193を新規に制作した2例です。台本、本人写真、LINE情報、指定参考を入力しています。制作中の確認・修正を含みます。No193は図の親レビュー1件と保存ガイドのリンク修正1件を受け、両ケースとも各主要工程を点検する最終スキルの記述を再読して仕上げています。初回無修正の自動生成という主張はしていません。

閲覧入口はトップページ、今回の2例は draft-v2/、インストール用ZIPは downloads/bonus-production.zip。直前の初稿は draft/no197/ と draft/no193/、それ以前の出力は repro/、No196修正版は sample/ に残しています。新しい2例と旧版を同じ状態として扱いません。

デモページの参考動画は、各台本フォルダにある実際の参考動画を閲覧用に追加したものです。凍結済みの特典制作へ追加で入力した動画ではありません。
