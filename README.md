# 特典作成スキルのデモ：いそっちさん Before → After

利用者指定の連携特典と塗り絵しおり特典を、そのままBeforeとしてリンクします。Beforeには元から属人性があります。各Googleドキュメントの台本を起点に、現在配布中のスキルでいそっちさんのAfterを新しく制作した2例です。

本人の参照画像と各特典の案内先・提供内容は、利用者の回答によりBeforeから事前設定として継承しました。制作担当へ渡した本文の材料は台本部分で、Beforeの本文・コマンド・図解は渡していません。制作中の自己確認と修正を含み、文字どおり台本だけの無修正出力という主張はしていません。公開担当は凍結後のAfter本文・画像へ個別修正を加えず、そのまま掲載しています。

入口と比較本体は `compare-isocchi/`。Beforeは元のNetlify公開ページ、元動画は指定Instagram投稿、使用台本は指定Googleドキュメントへリンクします。元の特典や動画は編集・差替えをしていません。`compare-isocchi/evidence.json`に出所と入力条件を記録しています。

各例の「解説動画の撮影台本」は折りたたみで閲覧できます。本人の16:9解説動画は撮影待ちで、現在は全文撮影台本と上部掲載準備までです。使用したスキルZIPは `downloads/bonus-production.zip`。再生成は公開リポジトリ外の `update_isocchi_demo.py`、従来の `update_demo_videos.py` からも現在の比較入口へ振り分けます。

以前の比較は `compare-no155/`、以前の2例は `draft-v3/`、それ以前は `draft-v2/`・`draft/no197/`・`draft/no193/`・`repro/`・`sample/` に保持しています。
