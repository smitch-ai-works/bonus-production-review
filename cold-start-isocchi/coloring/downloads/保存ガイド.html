保存した一式の使い方

ZIPを展開したら、index.htmlを開いて、画像を作る指示文から始めます。個別ファイルだけ保存した場合は、このガイドのリンクから必要なものを開けます。

僕がおすすめするのは、日本好きの海外の人向けの塗り絵しおり。「稼げる方法」だけを聞くより、富士山・湖・小舟のように売る題材を決めてから、チャッピーへ渡します。

1. 自分のテーマで線画を作る

画像を作る指示文を開き、【テーマ】を変えてChatGPTで画像作成。出来上がった画像を保存します。汚れや細かすぎる線は修正指示文で直し、塗れる面を確認。

2. 同じ画像でPDFと英語を作る

採用画像を添付し、PDF・英語を作る指示文を送ります。実際のPDF見本と英語原稿見本を見比べ、1デザイン×3本、50×150mm、A4のみという条件が一致するか確認します。印刷は実際のサイズ・100%。試し刷りして切り、塗れるか確かめます。

この練習PDFと商品画像は、自分用に内容を試すための見本です。見本をそのまま再配布・販売せず、販売用は自分のオリジナルの入力とデザインで新しく作ってください。

3. Etsyへ渡す

出店済みならShop Manager → Listings → Add a listingへ。商品の種類をDigital filesにし、商品画像、商品名、説明文、タグ、購入者用PDFをそれぞれ入力。

AIを使ったことを説明文に記載します。価格・通貨と手数料を確認し、Save as Draftで読み直してから公開を判断します。
