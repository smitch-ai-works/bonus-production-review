# このフォルダーの役割分担

このフォルダーの `brief.md` だけを今回の制作要件にする。
Claude Codeは構成設計・要件の整理・最終確認を担当する。
Codex CLIは `codex exec` による実装・修正を担当する。
実装依頼には入力ファイル名、成果物名、要件、確認基準を含める。
既存ファイルの外部公開、送信、削除、購入、権限変更、新規接続は行わない。
現在のフォルダー以外を探索しない。認証情報や個人情報を読まない。
Codex実行が許可されない・失敗した場合は、権限を緩めたり自作へ置き換えたりせず、未実行を報告する。
両AIが合意しただけで完成にせず、brief.mdと完成ファイルを照合する。
