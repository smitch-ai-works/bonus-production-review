# 16:9解説動画 撮影用台本

制作名：いそっち式 AI社員のつくり方

仮尺：6〜8分程度。セリフ量と操作箇所からの見積りで、AIの処理待ちは含まない。本人解説動画は未受領。

## 撮影準備

- 1920×1080、横16:9。冒頭と2か所の判断説明で本人カメラを出し、操作は画面を大きく見せる。
- `index.html`、展開した`ai-team-practice`、Claude Code、ブラウザを用意。個人の通知・アカウント・履歴は写さない。
- `posts.csv`は練習データ。自分の実績と呼ばない。完成例は`sample/report.html`、変更前は`sample/report-before.html`。
- 本撮影では導入・認証・設定保存を本人が実際に確認する。既に導入済みなら設定し直さず、「導入が必要な方はこの順」と資料を示す。以下のセリフもその場合分けに従う。
- 作成指示文と修正指示文の〈作業フォルダの絶対パス〉は、撮影用フォルダの実パスへ全置換して準備する。視聴者へ秘密情報を貼らせる説明はしない。

## 1　何を渡すか

画面：LPの表紙。本人カメラを出す。

セリフ：
「いそっちです。ChatGPTとClaude、別々に開いて、同じ説明を何回もしてませんか。今回はこの2つをつないで、仕事を受け渡せるコンビにしていきます。僕は、設計と最終確認はClaude Code、実際に手を動かす作業はCodex、って分けて使ってます。接続して終わりじゃなくて、レポートを1つ作って、直すところまで一緒にやってみましょう。」

画面：動画掲載枠を短く通過し、「完成見本｜練習データ」へ。完成レポートを開く。

セリフ：
「今回作るのは、これ。SNSの投稿をまとめたレポートです。これは練習用の6投稿で、僕の実績の数字じゃありません。リーチと保存をまとめて、保存率の高い投稿を出してます。最後はこのTOP3を横棒に変えるところまでやります。」

操作：完成例のサマリー、TOP3、一覧を順にゆっくり見せる。LPへ戻る。

## 2　Claude CodeにCodexを追加

画面：LP「01 接続する」の詳細を開く。未導入なら実際のClaude Codeの入力欄へ。導入済みなら資料を拡大して示す。

セリフ：
「まずはPCでClaude Codeが使える状態を用意します。Node.jsとChatGPTのアカウントも必要です。追加するコマンドは、この3つ。上から1つずつ、Claude Codeの入力欄へ送ります。1つ目がプラグインの場所を追加、2つ目がインストール、3つ目で読み込み直します。確認が出たら、内容と導入する範囲を見て進めてください。」

操作：`/plugin marketplace add openai/codex-plugin-cc`、`/plugin install codex@openai-codex`、`/reload-plugins`を資料で順番に指す。必要な場合だけ実送信して画面を確認。各操作後に2秒。

セリフ：
「次は、スラッシュcodexコロンsetup。今の準備状況を確認するコマンドです。Codexがまだ入っていなければ、この案内に沿って準備します。」

操作：`/codex:setup`。未ログインの場合のみ`!codex login`を送り、サインインは録画を止めるか個人情報を隠す。既ログインなら再認証をしない。

セリフ：
「ログインが必要な方は、こちら。ブラウザが開くので、ChatGPTのアカウントでサインインします。戻ったら、もう一度setupで準備できているか確認。ここまでできたら、役割を決めていきます。」

## 3　役割を残す

画面：LP「02 役割を残す」。人物場面→図→詳細を開く。

セリフ：
「僕がやりたいのは、両方から別々に答えをもらうことじゃなくて、1つの仕事を仕上げてもらうことなんですよね。だから、Claudeが設計、Codexが実作業、Claudeが確認。この順番にします。直すところがあればCodexへ戻す。ここを指示文に入れてます。」

操作：役割分担の全文コピー。練習用フォルダを開いたClaude Codeへ貼る。既存ルールとの矛盾・保存先を確認し、本人の許可範囲で保存する。保存処理を撮影する場合は、ファイルが実際に書かれたことを開いて確認。

セリフ：
「この指示は、今作業するフォルダのCLAUDE.mdに残します。既存の内容を消さずに保存して、読み返すところまで。次回も同じフォルダを開いて、context allで読み込まれているか確認してください。『覚えました』っていう返事だけで終わらせないのが大事です。」

操作：保存先のファイル内容と、必要なら新しいセッションで`/context all`を確認。未実施なら編集時に成功を語るカットへ差し替えない。

## 4　6投稿をレポートにする

画面：LP「03 作ってもらう」→「練習ファイル一式を保存」。ZIPを展開し、`guide.html`を開く。フォルダのCSVも開く。

セリフ：
「一式を保存して、ZIPを展開します。guide.htmlが保存版のガイド、posts.csvが今回使うデータです。完成例も入ってます。まずは自分のデータを入れる前に、この6投稿で1回動かしてみてください。」

操作：Claude Codeで展開フォルダを開く。作成指示文のパス欄を実際のパスへ置換するところを見せる。

セリフ：
「ここだけ自分のフォルダの場所に変えます。入力のCSVと、出力するHTMLの場所をはっきり渡します。保存率は、保存をリーチで割った数字。全体では合計同士で計算します。Claudeに設計してもらって、実装はCodexに渡してもらいます。」

操作：指示文を送信。処理待ちは無言で待ち、編集で短縮可能。Codexへ委譲されたことを実際の表示で確認。実行を省略して見本を見せる場合は「完成見本を先に見ます」と話す。

セリフ：
「ここでCodexへ仕事が渡っています。返答が来たら、Claudeに元のCSVとファイルを確かめてもらいます。もしファイルがないと言われたら、作業フォルダと入力、保存先の絶対パスをもう一度指定してください。」

## 5　完成物を確かめ、横棒へ変える

画面：実際に作成された`report.html`を開く。元CSVと並べる。未作成なら同梱見本を開き、「見本」と明言する。

セリフ：
「できたファイルを開きます。合計リーチが7,000、保存が245。245を7,000で割って100を掛けるので、全体保存率は3.5%。TOP3は6、5、4%です。まず、ここが揃っているか見ます。数字と見た目は、分けて確認します。」

操作：LP「04」の修正指示文を開いてコピー、パスを置換し、Claude Codeへ送信する。

セリフ：
「次はこのTOP3を横棒にします。数字はそのまま、見た目だけ比較しやすく。これも、Claudeが変更を整理して、Codexが作業。直ったら、もう一度ファイルを開いて確認します。」

操作：実際の修正ファイルを再読み込み。6.0/5.0/4.0%、棒の長さ、サマリーの3.5%を確認。待つ場合は`/codex:status`、終了結果は`/codex:result`。必要な修正が残れば、その内容を追加で渡す。

セリフ：
「僕が良いと思ってるのは、作業を任せながら、別のAIの目でも確認できるところです。ただ、両方に利用上限はあります。分担したら必ず消費が減る、ずっと止まらない、というわけではないので、実際の使い方に合わせて見てください。」

## 6　まず試す一手から案内へ

画面：LPの完了チェックを3つ確認。最後のCTA。

セリフ：
「レポートを開けて、数値が合って、横棒への修正もできたら、今回はOKです。まずはこの6投稿で1回。そのあと自分のCSVに置き換えてみてください。投稿の集計を任せられたら、次はSNSをどう収益につなぐか。そこを7日間の音声で学ぶ案内も用意しています。興味のある方は、最後のバナーから内容を見てみてください。」

操作：CTAは案内先を示すところまで。登録・購入を実演しない。収益や時間の保証を口頭で追加しない。

## 動画受領後の組込み

受領形式：横16:9のMP4（H.264映像/AAC音声推奨）、または本人が指定する埋込可能なURL。

LP `index.html` と保存版 `guide.html` の `#explainer`。見出し直下の`.bonus-video-placeholder`を、同じ場所の`<video controls playsinline preload="metadata" src="assets/explainer.mp4"></video>`へ置換する。動画受領待ちの案内を外す。ZIPも同じ版で再作成する。

スマホ/PCで比率、再生、音、シーク、終端を確認し、全編再生・実聴した範囲だけを記録する。現時点では動画ファイルを参照していない。
