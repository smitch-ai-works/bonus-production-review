# note記事の材料

このファイルを編集して保存します。`【記入】`は自分の言葉へ置き換えてください。記事条件と参考5本を先に用意し、質問への回答・構成の採用はAIが提示してから入力できます。

本名、会社名、顧客名、連絡先、非公開の仕事情報は入れず、共有してよい内容だけを使います。

## 記事の条件

- 主題：【記入】
- 読者と場面：【記入】
- 読者の困りごと：【記入】
- 読後にできる一つのこと：【記入】
- 自分の経歴・得意なことの概要（任意）：【記入／質問を受けてから答える】
- 今回使ってよい自分の事実・経験（任意）：【記入／質問を受けてから答える】
- 実績や数値の根拠（なければ「なし」）：【記入】
- 実物・手順・例として見せてよいもの：【記入／未定】
- 無料／有料で渡したい範囲：【記入／未定】
- 文体・避けたい言い方：【記入／質問を受けてから答える】
- 公開したくない話：【記入／なし】

記入例（架空）：主題「会議後のメモを、担当・期限が分かる依頼文へ変える」。読者「会議後のタスク依頼で確認の往復が起きる会社員」。得られるもの「担当・期限・成果物・未確定事項を分けた依頼文の型」。これは説明用で、あなたや作者の実体験・実績ではありません。
