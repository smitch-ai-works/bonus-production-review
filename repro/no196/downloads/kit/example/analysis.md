# 練習例の分析
教材内の創作データ5本を使用。実売・人気の証明はありません。
採る構造：読み手を絞る→困りごと→完成見本→手順→記入例→確認。
強み候補：①分類する手順 ②記入例付きテンプレート ③共有前チェック。
採用：②を主役にし、①③を使い方へ組み込む。
根拠：架空プロフィールの回答4・7・8。
構成修正：「議事録を整理」「メモをまとめる」の重複を、「メモを3種類に分ける」「決定事項を一文にする」へ変更。
理由：構成を先に決めると、読者の行動を分類→文章化の順へそろえられる。
語調の修正：3分類と手順を変えず、「分類しましょう」を「まずはここだけ。3つに分けます」へ変更。
